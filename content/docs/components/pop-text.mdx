<Step>Add the hover cascade to your `globals.css`.</Step>

```css
.pop-text-letter {
  transition:
    0.35s font-weight,
    0.35s color;
}

.pop-text-letter:hover {
  font-weight: 900;
  color: var(--pop-text-hover, #e0e7ff);
}

.pop-text-letter:hover + .pop-text-letter {
  font-weight: 500;
  color: color-mix(in srgb, var(--pop-text-hover, #e0e7ff) 50%, currentColor);
}

.pop-text-letter:hover + .pop-text-letter + .pop-text-letter {
  font-weight: 300;
}

.pop-text-letter:has(+ .pop-text-letter:hover) {
  font-weight: 500;
  color: color-mix(in srgb, var(--pop-text-hover, #e0e7ff) 50%, currentColor);
}

.pop-text-letter:has(+ .pop-text-letter + .pop-text-letter:hover) {
  font-weight: 300;
}
```

<Step>Update the import paths to match your project setup.</Step>

</Steps>

## Props

| Prop         | Type     | Default      | Description                                    |
| ------------ | -------- | ------------ | ---------------------------------------------- |
| `text`       | `string` | **Required** | The string to render, split into letters.      |
| `color`      | `string` | `"#a5b4fc"`  | Base text color (any CSS color).               |
| `hoverColor` | `string` | `"#e0e7ff"`  | Color of the hovered letter.                   |
| `className`  | `string` | `""`         | Extra classes on the wrapping heading element. |
