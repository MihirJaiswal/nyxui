## Usage

```tsx
import { ScribbleCircle } from "@/components/ui/scribble-circle";
```

```tsx
<h1>
  Stream every <ScribbleCircle word="Episode" /> the same hour it airs
</h1>
```

Pick a different look with `variant`:

```tsx
<ScribbleCircle word="underline" variant="underline" />
<ScribbleCircle word="box" variant="box" />
<ScribbleCircle word="highlight" variant="highlight" />
```

## Props

| Prop          | Type                                              | Default      | Description                               |
| ------------- | ------------------------------------------------- | ------------ | ----------------------------------------- |
| `word`        | `string`                                          | **Required** | The word to scribble around.              |
| `variant`     | `"circle" \| "underline" \| "box" \| "highlight"` | `"circle"`   | Scribble shape.                           |
| `stroke`      | `string`                                          | `"#FACC15"`  | Pen color (any CSS color).                |
| `strokeWidth` | `number`                                          | `3`          | Pen width in pixels (not on `highlight`). |
| `className`   | `string`                                          | `""`         | Extra classes on the wrapping span.       |
