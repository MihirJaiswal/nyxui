## Usage

```tsx
import { TypingWords } from "@/components/ui/typing-words";
```

```tsx
<h1 className="text-5xl font-bold">
  Ship faster with{" "}
  <TypingWords
    words={["less code", "clean design", "pure motion", "zero config"]}
    startIndex={1}
    typingSpeed={70}
    deletingSpeed={35}
  />
</h1>
```

## Props

| Prop                | Type       | Default       | Description                                                 |
| ------------------- | ---------- | ------------- | ----------------------------------------------------------- |
| `words`             | `string[]` | —             | Words the headline cycles through.                          |
| `startIndex`        | `number`   | `0`           | Index of the word the cycle starts at.                      |
| `typingSpeed`       | `number`   | `50`          | Time between each typed character, in ms.                   |
| `deletingSpeed`     | `number`   | `typingSpeed` | Time between each deleted character, in ms.                 |
| `pauseAtEnd`        | `number`   | `1000`        | How long the fully-typed word holds before deleting, in ms. |
| `characterDuration` | `number`   | `0.3`         | Per-character reveal duration, in seconds.                  |
| `className`         | `string`   | —             | Extra classes on the animated span.                         |
