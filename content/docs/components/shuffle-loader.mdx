## Props

| Prop        | Type     | Default | Description                                                               |
| ----------- | -------- | ------- | ------------------------------------------------------------------------- |
| `count`     | `number` | `5`     | Number of blocks in the row.                                              |
| `size`      | `number` | `32`    | Width/height of each block in pixels. Also drives the lift/drop distance. |
| `className` | `string` | —       | Classes for the outer flex container.                                     |
