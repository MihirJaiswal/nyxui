## Usage

```tsx
import { LogoCycle } from "@/components/ui/logo-cycle";
```

```tsx
<LogoCycle
  pairs={[
    {
      top: <SiTailwindcss className="text-[#0DA5E9]" />,
      bottom: <SiHtml5 className="text-[#DD4A25]" />,
    },
  ]}
/>
```

## Props

| Prop        | Type              | Default | Description                                                                |
| ----------- | ----------------- | ------- | -------------------------------------------------------------------------- |
| `pairs`     | `LogoCyclePair[]` | —       | The logo pairs to swap in each cell. `top` shows first, `bottom` swaps in. |
| `columns`   | `number`          | `3`     | Number of columns in the grid.                                             |
| `duration`  | `number`          | `10`    | Full swap cycle length, in seconds.                                        |
| `iconSize`  | `number`          | `24`    | Icon size in px.                                                           |
| `className` | `string`          | —       | Classes for the outer section.                                             |
