## Usage

```tsx
import {
  HoverImageLink,
  HoverImageLinks,
} from "@/components/blocks/hover-image-links";
```

### Basic Usage

```tsx
<HoverImageLinks>
  <HoverImageLink
    heading="Seasonal"
    subheading="Simulcast titles airing right now"
    imgSrc="/images/seasonal.jpg"
    href="/seasonal"
  />
  <HoverImageLink
    heading="Studios"
    subheading="Browse by animation studio"
    imgSrc="/images/studios.jpg"
    href="/studios"
  />
</HoverImageLinks>
```

## API

### `<HoverImageLinks>`

Dark section wrapper.

| Prop        | Type        | Default | Description                   |
| ----------- | ----------- | ------- | ----------------------------- |
| `children`  | `ReactNode` | —       | `<HoverImageLink>` children.  |
| `className` | `string?`   | —       | Extra classes on the section. |

### `<HoverImageLink>`

A single row. On hover the heading letters scatter apart one by one, a thumbnail appears and follows the cursor with springy easing, and an arrow fades in from the right.

| Prop         | Type      | Default | Description                                                     |
| ------------ | --------- | ------- | --------------------------------------------------------------- |
| `heading`    | `string`  | —       | Big label. Each letter animates independently on hover.         |
| `subheading` | `string`  | —       | Smaller label underneath.                                       |
| `imgSrc`     | `string`  | —       | Thumbnail source. Rendered as a springy overlay while hovering. |
| `href`       | `string?` | `"#"`   | Link target.                                                    |
| `className`  | `string?` | —       | Extra classes on the row anchor.                                |
