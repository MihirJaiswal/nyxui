## Usage

```tsx
import { ExpandableToolbar } from "@/components/blocks/expandable-toolbar";
import { Folder, MessageCircle, User, WalletCards } from "lucide-react";
```

### Basic Usage

```tsx
const items = [
  {
    id: 1,
    label: "User",
    icon: <User className="size-4.5" />,
    content: <p>Profile panel body</p>,
  },
  {
    id: 2,
    label: "Messages",
    icon: <MessageCircle className="size-4.5" />,
    content: <p>You have 3 new messages.</p>,
  },
  {
    id: 3,
    label: "Documents",
    icon: <Folder className="size-4.5" />,
    content: <p>Project_Proposal.pdf</p>,
  },
  {
    id: 4,
    label: "Wallet",
    icon: <WalletCards className="size-4.5" />,
    content: <p>Balance: $1,250.32</p>,
  },
];

<ExpandableToolbar items={items} />;
```

Click an icon to expand the panel; click it again (or click anywhere outside) to collapse. The panel width is locked to the toolbar width so it never overflows the icons.

## API

### `<ExpandableToolbar>`

| Prop        | Type            | Default | Description                       |
| ----------- | --------------- | ------- | --------------------------------- |
| `items`     | `ToolbarItem[]` | —       | Array of toolbar items to render. |
| `className` | `string?`       | —       | Extra classes on the root.        |

### `ToolbarItem`

| Field     | Type               | Description                                |
| --------- | ------------------ | ------------------------------------------ |
| `id`      | `number \| string` | Unique identifier for the item.            |
| `label`   | `string`           | Accessible label for the icon button.      |
| `icon`    | `ReactNode`        | Icon rendered inside the toolbar button.   |
| `content` | `ReactNode`        | Panel content shown when the item is open. |
